# Skill 改造验证记录

## 当前结论

已支持六种本地输入：文字型 PDF、UTF-8 Markdown（`.md` / `.markdown`）、纯文本（`.txt`）、本地 HTML/HTM、Word（`.docx`）、单文件 LaTeX（`.tex`）。与 v0.2.0 的输入范围一致。不支持 EPUB、OCR 扫描件、远程 URL 抓取或其他语言方向。HTML 只解析本地文件；TeX 不展开 `\input` / `\include`，也不编译。

Windows、真实宿主上的 Skill 自动发现/触发，以及 Claude Code / WorkBuddy 尚未在本记录中独立实测。DeepSeek Harness 的项目级安装更新与既有译稿修订已核对，见 2026-10-09 同步记录；这不代替一句指令从空白工作区翻译全文的验证。

2026-10-08 的图表、公式、参考文献、阅读排版与导出校验优化，以及 2026-10-09 的表格释义、术语别名与裁图边缘优化，已纳入当前源码，并同步到 v0.5.0 更新后的精简安装包。下方“本地未发布”是各轮验证当时的状态，不表示当前源码或安装包缺少相应实现。

下方各节是历次改造当时的验证记录（环境、测试数量和“尚未支持更多格式”都是当时的结论）。那些数字和范围不要当成当前能力；输入范围以本节为准。
