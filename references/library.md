# 可选本地文献库

使用处理文献或文章时同一个 WORKSPACE。`serve` 不转换、不翻译，只展示已经保存的数据。

```sh
python "<SKILL_DIR>/scripts/paper_reader.py" --workspace "<WORKSPACE>" serve --port 8765
```

打开 http://127.0.0.1:8765 。仅回环监听，不暴露公网。端口占用时选择另一个端口，不杀死已有服务。停止自己启动的服务不删除文献。

网页提供多篇列表、对照阅读、可调侧栏、术语/笔记切换、原文定位、修订与批注。Agent解释入口生成问题供复制给当前会话，不主动调用模型。用户修改使相关复核失效；要重新交付通过检查的HTML，应由Agent复核当前版本后导出。

数据在 WORKSPACE/data；导出在 WORKSPACE/exports；依赖在 WORKSPACE/.runtime，缓存在 WORKSPACE/.cache。备份整个工作目录可保留来源和笔记；迁移机器时重建.runtime，不跨操作系统复制虚拟环境。不要删除用户工作目录来更新Skill。

## 首次使用与恢复

1. 对相同工作目录运行 `doctor`，若缺少或升级了依赖再运行 `setup`。
2. 用户需要文献库时启动 `serve`，返回实际端口和链接；单篇HTML交付无需这一步。
3. 首页自动列出工作目录data中的文献。若列表为空，先检查是否用了处理文献或文章时的工作目录，不要重新导入或迁移用户数据。
4. 关闭服务后再次使用同一目录启动，文献、笔记和修订仍然保留。端口变化不影响存储。

## 阅读、修改与导出

- 目录跳转、多级标题、句子联动、搜索、字号、译文显隐及左右栏拖动直接在阅读页使用。
- 段落“…”集中提供原文定位、术语释义、修订译文和标记疑难；选中文字可以添加锚定笔记。
- 右栏在术语和笔记两个tab间切换。修订保留历史，Agent不能覆盖用户改过的译文。
- 保存笔记不需要重新翻译。修改译文或术语后，读取 `progress ID` / `tasks ID`，复核当前版本并提交相应review/full_review，再导出。
- 出现版本冲突时，重新读取并核对，不通过重试旧内容覆盖新笔记。孤立笔记在页面提示重新关联。

## 实现位置

本文件只是操作说明，实际功能已随包交付：`scripts/reader/server.py` 提供本地HTTP服务，`store.py` 提供持久化，`workflow.py` 处理版本与编辑保护，`exporter.py` 生成快照，`assets/reader/` 是完整构建后的界面。无需另行下载旧项目。

## 常见问题

- 页面无法打开：确认服务进程仍运行，地址和端口一致；不擅自停止用户其他进程。
- 安装包更新后无法运行：对原工作目录重新setup；不要删除data。
- 离线HTML中没有编辑按钮：这是只读快照的设计，回本地服务编辑再导出。
- 只有HTML、没有工作目录：仍可阅读快照，但当前不支持从HTML恢复可编辑文献库。
